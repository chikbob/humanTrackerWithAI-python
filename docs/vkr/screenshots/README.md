# Скриншоты интерфейса для ВКР

Каталог содержит реальные скриншоты, автоматически снятые с локально запущенного `Streamlit`-приложения.

- `dashboard.png` — главный экран дашборда.
- `monitoring_focus.png` — онлайн-мониторинг в режиме фокусного отображения.
- `monitoring_grid_2x2.png` — онлайн-мониторинг в режиме сетки.
- `live_window.png` — отдельное окно `live-window`.
- `journal.png` — журнал событий с фильтрами и карточкой события.
- `analytics.png` — экран аналитики.
- `employees.png` — раздел справочника сотрудников и статуса синхронизации.
- `sources.png` — список и статусы источников видео.
- `settings.png` — раздел системных настроек.

Скриншоты используются при сборке файла `ВКР_Кольцов.docx`.
