# UML-диаграммы ВКР

В каталоге собраны отдельные `PlantUML`-файлы, соответствующие встроенным диаграммам из Markdown-версии пояснительной записки.

- `01_architecture.puml` — общая архитектура системы.
- `02_components.puml` — компонентная структура приложения.
- `03_use_cases.puml` — диаграмма вариантов использования.
- `04_domain_model.puml` — логическая модель предметной области.
- `05_database_schema.puml` — схема базы данных.
- `06_ui_worker_interaction.puml` — взаимодействие UI, worker и прикладных подсистем.
- `07_entry_event_sequence.puml` — последовательность обработки ключевого события.
- `08_event_logic.puml` — схема событийной логики.
- `09_deployment.puml` — диаграмма развертывания.
